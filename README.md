# Memories — diário aberto

Um diário/autobiografia público e anônimo. Pessoas não são identificadas; os textos registram somente os sentimentos, escolhas e mudanças de Rafael.

## Como publicar uma nova página

1. Abra **Issues** neste repositório e clique em **New issue**.
2. O título deve começar exatamente com `[DIÁRIO]`.
3. Na primeira linha, escreva os sentimentos separados por vírgulas:

   `Sentimentos: saudade, coragem, recomeço`

4. Depois de uma linha em branco, escreva livremente e publique a issue.
5. A nova página aparecerá automaticamente no site. Editar ou excluir a issue também atualiza o conteúdo exibido.

Exemplo de título: `[DIÁRIO] O dia em que escolhi continuar`

## Publicação no GitHub Pages

Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main`, pasta `/ (root)` e salve.

O site não usa token, senha ou banco de dados. Ele lê apenas issues públicas deste repositório cujo título começa com `[DIÁRIO]`.
